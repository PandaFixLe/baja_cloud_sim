# v1.1 待办清单

目标：在 v1.0 基线上把潘的 Stanley + 阻尼 + 滤波控制律集成进 `path_follower_node.py`，并
把 follow 从"无条件信任"补到"先验 + 兜底"。本版本不改变话题名/消息类型与表现契约，
RViz、Gazebo 桥接、录像、评价节点不受影响。

## 范围（v1.1 必做）

### 控制律移植

- `core.py` 新增 `StanleyControllerConfig` 与 `stanley_path_control(...)` 纯函数，控制
  律由潘的实现提炼（Stanley 主项 + PD + cte_dot 阻尼 + yaw_rate 阻尼 + 动态最大转角 +
  前方曲率预判主动减速）。
- 控制律所需的有状态量（`prev_error / prev_steering / prev_yaw / prev_cte /
  yaw_rate_filtered`）显式传入传出，便于单测与回归。
- `path_follower_node.py` 薄壳改用 `stanley_path_control`，参数增加
  `controller_mode ∈ {legacy, stanley}`，`legacy` 保留作回退。
- `controller_mode` 默认 `stanley`；`legacy` 用于回归对比与故障兜底。

### 参数新增（仅新增，不改既有）

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `controller_mode` | `stanley` | 选择 `legacy` 或 `stanley` |
| `kp_heading` | 1.2 | 已有，复用为 Stanley 模式的 P 增益 |
| `kd_heading` | 0.3 | D 增益（阻尼振荡） |
| `k_stanley` | 0.8 | Stanley 横向偏差增益 |
| `k_cte_dot` | 0.15 | 横向偏差变化率阻尼增益 |
| `k_yaw_rate` | 0.5 | yaw 角速度阻尼增益 |
| `steering_alpha` | 0.6 | 转向输出低通滤波系数 |
| `max_steer_rate_deg` | 8.0 | 最大转向角速率，度/周期 |
| `adaptive_steering` | True | 是否按曲率动态限制最大转角 |
| `adaptive_speed` | True | 是否按转角/曲率降速 |

### Follow 节点精简（必须砍）

- 移除 CSV 加载相关逻辑（本工程本来就用 `/planned_path`，确认无残留即可）。
- 移除实车四轮转向（`/rear_steering_cmd`、`/four_wheel_steering_active`）的发布与参数；
  代码可保留为参数门控的"扩展位"，默认全部关，不影响仿真。
- 移除"避障"状态机残留：确认无任何"读CSV → 遇障碍 → 切状态 → 再读CSV"的逻辑。

### Planner CSV 日志（旁路、可失败不致命）

- `frenet_planner_node.py` 新增参数 `enable_path_log`（默认 `True`），
  `path_log_dir`（默认 `results/seed_<seed>`）。
- 每个规划周期把当前 `/planned_path` 写入 `planned_path_<timestamp>.csv`：
  `timestamp_s, x, y, yaw, seq`。
- 写文件必须 `try/except`；写失败仅打 warn，绝不阻塞 10 Hz 发布或导致节点崩溃。
- 退出时 flush；不接管 / 不影响 `/planned_path` 的发布时机。

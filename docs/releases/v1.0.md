# v1.0 发布说明

本分支 `Baja-resource-origin-7.23-v1` 对应大框架工程的 v1.0 基线。本版本不改变代码逻辑，仅
完成"分层架构 + 文档骨架"的固化，作为后续 v1.1 集成 Stanley 控制律的起点。

## 版本定位

v1.0 是"分层架构定型版"，明确把工程拆成两段：

```text
原始/参考路径 ──► 上层 replanner（frenet，规划核心）──► /planned_path ──► 下层控制器（path_follower）
```

远端规划由 `frenet_planner_node.py` 负责；近端控制由 `path_follower_node.py` 负责，二者通过
`/planned_path`、`/planner/status` 两个话题解耦。避障已上移至 replanner，follow 不再处理
障碍物。

## 已包含内容

- **Frenet 局部规划器**：分层撒点 + 动态规划选路，10 Hz 输出 `/planned_path`，详见
  [`docs/frenet_planner.md`](../frenet_planner.md)。
- **路径跟踪控制器**：`legacy_path_control`（纯航向 P + 预瞄 + 分档降速），订阅
  `/planned_path`、`/planner/status`、`/gps/fix`、`/imu/yaw`，发布 `/cmd_control` 与
  `/lookahead_point`。
- **控制回路基线**：20 Hz 定时器；可行性联锁（`/planner/status`）；路径新鲜度联锁
  （`/planned_path` > 400 ms 视为过期，立即停车）。
- **表现契约**：RViz、Gazebo 桥接、`video_recorder`、`evaluator` 所依赖的话题集合与消息
  类型已固定，本版本未改动。
- **文档**：
  - [`README.md`](../../README.md) 总览 + 代码结构 + 核心逻辑 + 时间戳已知问题；
  - [`docs/frenet_planner.md`](../frenet_planner.md) 规划核心深入说明；
  - 本文件 `docs/releases/v1.0.md`。

## 参数（v1.0 baseline）

`path_follower_node.py` 声明的参数：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `origin_latitude` | 30.0 | GPS→XY 局部平面原点纬度 |
| `origin_longitude` | 114.0 | GPS→XY 局部平面原点经度 |
| `target_speed` | 2.5 | 目标速度，m/s |
| `lookahead_distance` | 3.0 | 预瞄距离，m |
| `kp_heading` | 1.2 | 航向 P 增益 |
| `max_steering_angle` | 35.0 | 最大前轮转角，度 |

`frenet_planner_node.py` 参数见该节点源代码。

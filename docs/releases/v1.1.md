# v1.1 发布说明：Stanley 控制律移植 + 旁路 CSV 日志

> 本版本基于 `Baja-resource-origin-7.23-v1`（v1.0）演进。完整背景与决策依据见
> [`docs/planning/background-pan-code.md`](../planning/background-pan-code.md)。

## 一、为什么会有 v1.1

v1.0 已经把工程定型为"上层 replanner + 下层控制器"分层结构——`frenet_planner` 在远端
（~30 m 视野、10 Hz）解车道级避障，`path_follower` 在近端（几米预瞄、20 Hz）解跟踪精
度与平顺。但 `path_follower` 当时只用 `core.legacy_path_control`（纯航向 P + 预瞄
+ 分档降速），横向精度与稳定性不满足弯道性能目标。

与此同时，分项目合作中潘维护的实车版本 `path_follower_node_path3.py` 已经把同一几何
核心（追一个目标点）升级为 Stanley 主项 + PD + 双阻尼 + 滤波 + 速率限制，并附带避障、
4WS 等实车能力。**v1.1 的目标是把潘代码的"精华"提炼到本工程分层架构里**：
**避障彻底下移到 replanner、4WS 默认关闭、控制律抽进 `core.py` 纯函数**——保持话题
与表现契约零变更。详细背景见 `background-pan-code.md` 的第三、四、五节。

## 二、本次实施的范围

### 2.1 控制律：Stanley 主项 + PD + 双阻尼 + 滤波 + 速率限制

新增到 `core.py`：

- **`StanleyControllerConfig`**：继承 `ControllerConfig`（沿用其 `target_speed`、
  `lookahead_distance`、`heading_gain`、`max_steering_deg`），新增 9 个 Stanley 专属
  字段（PD、阻尼、滤波、自适应）。
- **`StanleyState`**：把 `prev_*`、`yaw_rate_filtered`、`last_nearest`、`initialized`
  显式声明为 dataclass 字段，由调用方持有并在多次调用间传入传出——便于单测与回归。
- **`stanley_path_control(current, yaw_navigation, path, config, state, dt)`**：
  - **Stanley 主项** `atan2(k_stanley · CTE, max(target_speed, 2.0))`，CTE 由
    `signed_lateral` 提供（与项目已有左正右负约定一致）。
  - **PD 主项** `kp · heading_error + kd · d_heading/dt`。
  - **双阻尼**：CTE 变化率（`k_cte_dot`）抑制横向冲出；航向角速度（`k_yaw_rate`，
    低通 `α=0.7` 后乘 `0.3`）抑制急弯出弯过冲。
  - **转向平滑**：自适应最大转角（按前瞻曲率收缩）、低通（`α=0.6`）、单帧速率限制
    （`max_steer_rate_deg`，防突变）。
  - **按转角分档降速**（与 legacy 表一致：`>30°/20°/12°/6° → 0.50/0.70/0.85/0.95`），
    可选按前方前瞻曲率自适应降速。
  - 节点以 navigation yaw（`/imu/yaw` 约定）传入；函数内部转为 math-frame
    `yaw_math = wrap_angle(π/2 − yaw_navigation)`，CTE 引用增广路径的 math-yaw，
    **节点公共契约零变更**。

辅助纯函数（也用于测试）：

- **`augment_path_for_cte`**：把 `(x, y)` 路径增广为带 math-yaw 的字典列表，使
  `signed_lateral` 与 `nearest_index` 能直接复用。
- **`preview_curvature`**：扫描 `max(3 m, target_speed × 1.2 s)` 路径，返回
  `|Δbearing|/Δs` 最大值，用于自适应最大转角与自适应速度。

### 2.2 节点：`path_follower` 的 `controller_mode` 分派

- 声明 9 个新参数（`controller_mode` + 8 个 Stanley 字段），全部带默认值（与
  `StanleyControllerConfig` 一致）。
- 在 `_control` 中按 `controller_mode ∈ {legacy, stanley}` 分派：
  - `legacy`：调用 `legacy_path_control`，与 v1.0 **字节等价**——保留作回退与回归对比。
  - `stanley`：调用 `stanley_path_control`，节点持有 `self.stanley_state`。
- 未知 `controller_mode` 值 → warn 并 fallback 到 `stanley`（v1.1 宽松策略）。
- 话题与发布频率（20 Hz）、`/cmd_control` 与 `/lookahead_point` 内容与签名：**未动**。

### 2.3 可观测性：planner 旁路 CSV 日志

- `frenet_planner_node` 新增 `enable_path_log`（默认 `true`）与 `path_log_dir`
  （默认 `results`）两个参数。
- 每个 10 Hz 规划周期写一个 `planned_path_<timestamp>.csv`，列：
  `timestamp_s, x, y, yaw, seq`（`yaw` 由相邻点 bearing 推导）。
- `destroy_node` 中 flush + close 文件。
- **写失败不致命**：`try/except OSError` 全程包裹；写失败仅 warn，绝不阻塞发布。
- 话题 `/planned_path` 与 10 Hz 发布频率：**未动**；CSV 写入在 `path_pub.publish`
  之后，不影响热路径。

### 2.4 文档与版本对齐

- `core.py`、`path_follower_node.py`、`frenet_planner_node.py` 与 `params.yaml` 同步
  声明新参数；`tests` 增 4 个 Stanley 测试。
- `setup.py` 早已声明 `1.1.0`；`__init__.py` 中 `__version__` 同步改为 `1.1.0`。

## 三、参数（v1.1 baseline）

`path_follower_node` 新增：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `controller_mode` | `stanley` | `legacy` / `stanley` 选择 |
| `kd_heading` | 0.3 | PD D 增益 |
| `k_stanley` | 0.8 | Stanley CTE 增益 |
| `k_cte_dot` | 0.15 | CTE 变化率阻尼 |
| `k_yaw_rate` | 0.5 | 航向角速度阻尼 |
| `steering_alpha` | 0.6 | 转向输出低通系数 |
| `max_steer_rate_deg` | 8.0 | 最大转向角速率（度/周期）|
| `adaptive_steering` | true | 按前瞻曲率动态限制最大转角 |
| `adaptive_speed` | true | 按前瞻曲率预判降速 |

`frenet_planner_node` 新增：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `enable_path_log` | true | 是否启用旁路 CSV 日志 |
| `path_log_dir` | `results` | CSV 输出目录 |

## 六、测试

```bash
cd /mnt/data/baja_cloud_sim
source /opt/ros/humble/setup.bash
source install/setup.bash
python3 -m unittest discover -s src/baja_cloud_sim/test -v
```

v1.1 在 v1.0 的 6 个测试基础上追加 4 个 Stanley 测试 + 1 个 preview_curvature 测试，
合计 10 个，全部通过：

- `test_stanley_straight_path_zero_steering`：直线路径上不产生转向。
- `test_stanley_cte_sign_corrects`：CTE > 0（左偏）应给出负转向（右转）。
- `test_stanley_state_persists_across_ticks`：状态对象在多次调用间保持一致；速率限制
  约束单帧转向增量。
- `test_stanley_short_path_returns_zero`：路径过短时短路返回零速零角。
- `test_preview_curvature_zero_for_straight`：直线路径前瞻曲率为零。

# v1.1 发布说明

本分支 `Baja-resource-origin-7.23-v1` 的 v1.1 在 v1.0 分层架构定型版基础上，移植潘
`path_follower_node_path3.py` 的 Stanley 控制律到下层控制器，并为上层 replanner 增加
旁路 CSV 日志。本版本保持话题与表现契约零变更。

## 版本定位

v1.1 是"控制律增强 + 可观测性增强"。结构上仍是：

```text
上层 replanner（frenet）──► /planned_path ──► 下层控制器（path_follower, Stanley）
```

v1.0 的 `legacy_path_control`（纯航向 P + 预瞄 + 分档降速）升级为 Stanley + PD + 双阻尼 +
转向滤波 + 速率限制。新增 `controller_mode` 参数，`legacy` 保留作回退与回归对比。

## 新增内容

- **`core.stanley_path_control`**：Stanley 主项 + PD + CTE 变化率阻尼 + 航向角速度阻尼 +
  转向低通滤波 + 转向速率限制。可选自适应最大转角与自适应速度。
- **`core.StanleyControllerConfig`**：继承 `ControllerConfig`，新增 9 个 PD/Stanley/滤波/
  自适应字段。
- **`core.StanleyState`**：控制器有状态量（`prev_*`、`yaw_rate_filtered`、`last_nearest`、
  `initialized`），显式传入传出，便于单测。
- **`core.augment_path_for_cte` / `core.preview_curvature`**：纯函数辅助，公开给测试。
- **`path_follower_node` 升级**：声明 9 个新参数；在 `_control` 中按 `controller_mode`
  分派 legacy / stanley 调用；节点持有 `self.stanley_state`。
- **`frenet_planner_node` 旁路 CSV 日志**：声明 `enable_path_log`、`path_log_dir` 两个参数；
  每个 10 Hz 周期写一个 `planned_path_<timestamp>.csv`；`destroy_node` 中 flush+close；
  全程 `try/except OSError`，写失败仅 warn。

## 参数（v1.1 baseline）

`path_follower_node` 新增/更新：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `controller_mode` | `stanley` | 选择 `legacy` 或 `stanley` |
| `kd_heading` | 0.3 | PD D 增益 |
| `k_stanley` | 0.8 | Stanley CTE 增益 |
| `k_cte_dot` | 0.15 | CTE 变化率阻尼 |
| `k_yaw_rate` | 0.5 | 航向角速度阻尼 |
| `steering_alpha` | 0.6 | 转向输出低通系数 |
| `max_steer_rate_deg` | 8.0 | 最大转向角速率（度/周期）|
| `adaptive_steering` | true | 按前瞻曲率动态限制最大转角 |
| `adaptive_speed` | true | 按前瞻曲率预判降速 |

`frenet_planner_node` 新增：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `enable_path_log` | true | 是否启用旁路 CSV 日志 |
| `path_log_dir` | `results` | CSV 输出目录 |

## 测试

```bash
cd /mnt/data/baja_cloud_sim
source /opt/ros/humble/setup.bash
source install/setup.bash
python3 -m unittest discover -s src/baja_cloud_sim/test -v
```

v1.1 在 v1.0 的 6 个测试基础上追加 4 个 Stanley 测试：

- `test_stanley_straight_path_zero_steering`：直线路径上不产生转向。
- `test_stanley_cte_sign_corrects`：CTE > 0（左偏）应给出负转向（右转）。
- `test_stanley_state_persists_across_ticks`：状态对象在多次调用间保持一致；速率限制
  约束单帧转向增量。
- `test_stanley_short_path_returns_zero`：路径过短时短路返回零速零角。

加上 `test_preview_curvature_zero_for_straight`：直线路径前瞻曲率为零。

合计 10 个单元测试，全部通过。
